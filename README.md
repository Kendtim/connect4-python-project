# Connect 4 – Python Project

A simple Connect 4 game developed in Python.

## About the Project

This project is a Python implementation of the classic Connect 4 game.
The goal is to connect four of your pieces horizontally, vertically, or diagonally before your opponent.

## Features

- Two-player gameplay
- Turn-based system
- Win detection
- Draw detection
- Simple and easy-to-use interface

## Technologies

- Python
